# Quattro Commas

Independent AI engineering studio run by [Kiliaan Vanvoorden](https://github.com/BoozeLee) (Riemst, Belgium).

**What we build**

- **Agent systems** — multi-agent tooling, MCP servers, and CLI/TUI engineering agents
- **Evaluation gates** — deterministic checksum-gated measurement instruments and tamper tests that must fail
- **Local inference** — local-first LLM tooling, Ollama-based pipelines, sidecar architectures
- **Applied ML** — industrial computer-vision and yield-prediction experiments for food processing

**Working agreements**

- Every number in a README is re-derivable from the repo itself or from a recorded measurement.
- No production deployments; everything here is built, tested, and maintained by one person.
- Security reports and questions: open an issue on the relevant repository.
